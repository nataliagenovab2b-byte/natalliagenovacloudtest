# Natallia Genova — HTML-макет сайта

Статический сайт на HTML, CSS и JavaScript, перенесённый из Figma. Без зависимостей во время работы сайта, внешних шрифтов и временных URL ресурсов.

## Запуск

Откройте `index.html` или запустите локальный сервер:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4173/.

## Сборка и публикация

Нужен Node.js 22.16+ или 24+.

```sh
npm run check
npm run build
```

Готовый сайт находится в `dist/`. Сборка копирует только HTML, CSS, JavaScript, используемые изображения и шрифты, проверяет внутренние якоря и отсутствие временных Figma URL.

- **Vercel:** настройки сборки и папки `dist/` заданы в `vercel.json`.
- **Cloudflare Pages:** framework `None`, команда `npm run build`, output directory `dist`.
- Можно также загрузить содержимое `dist/` на обычный статический хостинг.

Публикация на внешнем хостинге отдельно не выполнялась; изменения отправлены в подключённый GitHub-репозиторий.

## Структура

- `index.html` — все секции и тексты; атрибуты `data-figma-node` связывают секции с оригиналом.
- `styles.css` — локальные шрифты, измеренные дизайн-токены, стили секций и адаптация.
- `script.js` — пять историй пациентов, управление с клавиатуры и сохранение выбора cookies.
- `assets/figma/` — оригинальные изображения и SVG из Figma.
- `assets/fonts/` — существующие локальные Montserrat и Raleway. Georgia используется как системный шрифт.
- `scripts/build.mjs` — сборка статического сайта.
- `scripts/verify.mjs` — проверки в настоящем Chromium и сравнение с Figma через sharp.
- `design/` — исходная спецификация, эталон и отчёт о проверке.

## Повторение браузерной проверки

Нужны доступные модули `playwright` и `sharp`, а также Chromium. Они не требуются для сборки или работы сайта. Если модули установлены отдельно, укажите их расположение:

```sh
QA_MODULES=/absolute/path/to/node_modules \
QA_BROWSER=/absolute/path/to/chromium \
npm run test:browser
```

Проверка сама запускает временный сервер для `dist/`. Скриншоты, наложение, разностное изображение и JSON-отчёт сохраняются в `design/qa/`.

## Границы исходного макета

В Figma предоставлен один десктопный фрейм 3360 × 6119. Мобильная и планшетная адаптация выведены из его структуры; отдельными Figma-фреймами они не подтверждены. В макете нет компонентов, именованных стилей, переменных, Code Connect и аннотаций. API не предоставляет поле `devStatus`.

WhatsApp сохранён из существующего сайта. Instagram и LinkedIn подключены по адресам пользователя. Impressum и Datenschutz сохранены как подписи: тексты и адреса юридических страниц не предоставлены. Не добавлены вымышленные юридические документы или адреса.

Дополнительные трекеры не установлены. Обе кнопки cookies сохраняют выбранное значение; согласие само по себе не подключает сторонние сервисы.
