# Отчёт о переносе Figma → HTML

Источник: [Natallia Genova — Website Design](https://www.figma.com/design/4vYO0QbBU5F1ZGcHVrgw6w/Natallia-Genova-Website-Design?node-id=0-1&m=dev). Проверено 27 октября 2026.

## Что перенесено

Единственная страница `Page 1` (`0:1`), полный фрейм `1:2` размером **3360 × 6839**. Сохранены все **129 текстовых слоёв**, последовательность секций и пять историй пациентов, включая первоначально невидимые слайды.

| --- | --- | ---: | ---: |
| Шапка | `1:4` | 0 | 92 |
| Первый экран | `1:389`, `1:24` | 92 | 721 |
| С чего можно начать | `1:390`, `1:44` | 854 | 588 |

| Уведомление cookies при viewport 3360 × 6839 | `1:451` | 6689 | 98 |

Положение и высота этих секций в браузере совпали с Figma. Контентные контейнеры — 1400 px; первый экран — 1410 px. Остальные размеры, интервалы, цвета, градиенты, радиусы и тени взяты из структурированных ответов MCP. Матрицы градиентов карточек дополнительно проверены через read-only Plugin API.

Использованы `get_design_context` со скриншотом, `get_metadata`, `get_screenshot`, `get_variable_defs`, `get_code_connect_map`, `download_assets` и read-only `use_figma`. В исходном файле **нет** переменных, именованных локальных стилей, компонентов/вариантов, Code Connect и аннотаций. Чтение `devStatus` отклонено API как неподдерживаемое; утверждений о Ready for development нет. Исходный файл Figma не изменялся.

## Ресурсы и файлы

Из Figma выгружены и используются логотип, портрет первого экрана, портрет «Обо мне» и три исходных SVG для четырёх декоративных слоёв. Оригинальные изображения подключены локально; SVG не перерисованы, их собственные размеры сохранены. Проверены все семь мест использования изображений: координаты и размеры на эталонном viewport отличаются от спецификации менее чем на 0,1 px из-за округления браузера.

Повторно использованы существующие локальные Montserrat и Raleway. Для Georgia задан системный шрифт. Все CSS-токены сформированы из конкретных значений слоёв; это не именованные переменные исходного Figma-файла.

- Изменены `index.html`, `styles.css`, `script.js`.
- Добавлены `assets/figma/`, `package.json`, `vercel.json`, `.gitignore`, `README.md`.
- Добавлены сборка `scripts/build.mjs` и проверка `scripts/verify.mjs`.
- Эталон: `design/reference/figma-desktop.png`.
- Архив ответов MCP: `design/reference/figma-context.txt` и `design/figma-inspection.json`.
- Итоговые скриншоты, наложение, разностное изображение и полный JSON-отчёт: `design/qa/`.
- Готовая статическая сборка: `dist/`; архив для передачи: `natallia-genova-html.zip`.

Сборка содержит только HTML, CSS, JavaScript и восемь используемых локальных ресурсов. Старые фотографии и ZIP-файлы проекта не удалены и не попадают в сборку. Runtime-зависимостей нет.

## Что проверено

Проверка выполнена Playwright в настоящем Google Chrome/Chromium. Тестируется готовая сборка `dist/`, а не отдельный прототип.

| Viewport | Результат |
| --- | --- |
| 3360 × 6839 | Геометрия всех секций и исходных ресурсов; визуальное сравнение с Figma |
| 1920 × 1080 | Десктопная вёрстка |
| 1440 × 1000 | Уменьшенная десктопная вёрстка |
| 1024 × 900 | Планшетная горизонтальная вёрстка |
| 768 × 1024 | Планшетная вертикальная вёрстка |
| 390 × 844 | Мобильная вёрстка и интерактивные проверки |
| 320 × 740 | Узкий мобильный экран |

На всех размерах:

- отсутствуют горизонтальное переполнение, ошибки JavaScript, HTTP-ошибки ресурсов и ошибки консоли;
- все исходные тексты присутствуют; видимые текстовые блоки остаются внутри viewport;
- изображения и шрифты загружаются; у изображений есть `alt`, у ссылок и кнопок — доступные имена, на странице один `h1`;
- проверены все пять историй, предыдущая/следующая история, индикаторы, стрелки клавиатуры и высота каждого мобильного слайда;
- проверены обе кнопки cookies, сохранение после перезагрузки и работа при недоступном localStorage;
- проверены все основные якоря, три WhatsApp-ссылки и адреса Instagram/LinkedIn пользователя. Переходы с отправкой сообщений не выполнялись.

`npm run check`, `npm run build`, `npm run test:browser` и `git diff --check` проходят. Сборка проверяет внутренние якоря, существование локальных ресурсов и отсутствие временных Figma URL в исполняемой странице и CSS.

## Визуальная проверка и оставшиеся различия

Выполнено несколько проходов сравнения и исправлений: перенос заголовка услуг, межсекционные интервалы, высоты карточек, вертикальное положение CTA, блок «Обо мне», карусель, системный символ стрелки и меню при 320 px. Финальные границы секций совпадают с оригиналом, а изображения используются в исходных позициях и с исходным кадрированием.

Сохранены:

- `design/qa/3360x6839.png` — итоговый браузерный рендер;
- `design/qa/comparison.png` — Figma слева, браузер справа;
- `design/qa/overlay.png` — наложение с прозрачностью 50%;
- `design/qa/difference.png` — абсолютная разность изображений;
- `design/qa/report.json` — измерения по секциям и результаты проверок.

Финальный прогон содержит 66 автоматических проверок viewport/геометрии и отдельные интерактивные сценарии; ошибок нет.

Побитовой идентичности PNG нет. Для полного кадра средняя абсолютная разность RGB — 1,232 из 255; 1,176% пикселей имеют разность хотя бы одного канала больше 24. Для центральных областей отдельных секций этот показатель составляет 0,861–4,811%. Наблюдаемые различия включают растеризацию и метрики системной Georgia, сглаживание текста, отдельные переносы строк и композитинг теней/размытий. Точные CSS-параметры сохранены; системная Georgia не заменена приблизительным веб-шрифтом. Метрики разности в JSON приведены отдельно для полного изображения и центральных областей секций: процент всего кадра с большими пустыми полями не следует считать «процентом точности дизайна».

## Допущения и недостающие исходники

1. В Figma нет отдельных мобильных/планшетных фреймов. Адаптация выводится из структуры десктопа; сверка с отдельными мобильными эталонами невозможна. На меньших экранах колонки перестраиваются, высоты зависят от контента, навигация переносится, декоративные слои первого экрана скрываются на телефоне. Дополнительные украшения и анимации не добавлялись.
2. Instagram и LinkedIn добавлены по переданным пользователем адресам. WhatsApp взят из существующего проекта.
3. Тексты и адреса Impressum/Datenschutz не предоставлены. Их названия сохранены без ложных переходов и без вымышленных юридических текстов.
4. Контрастность исходных цветов не менялась. Выполнена базовая проверка доступности, а не полный аудит WCAG.
5. Проверка выполнена в Chromium; отдельные Safari/Firefox и реальные устройства не проверялись.
6. Коммиты, push, публикация в Vercel/Cloudflare и изменения удалённых файлов не выполнялись.
